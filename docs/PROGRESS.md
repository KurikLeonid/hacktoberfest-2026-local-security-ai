## M0: репо, инструменты, скелеты
- Склонирован пустой репозиторий, план положен в `docs/PLAN.md`.
- Установлены `ollama` (0.40) и `mitmproxy` через brew. В `backend` mitmproxy добавлен ещё и в uv-окружение (12.3), чтобы addon импортировал `core` с теми же зависимостями.
- `backend`: uv, Python 3.12+ (uv выбрал 3.13; системный 3.14 не используется).
- `frontend`: Vite + React 19 + TS + Tailwind 4, `/api` проксируется на :8000 в dev-режиме.
- **Отклонение**: gemma4:e4b весит 6,6 ГБ и качалась медленно (1–3 МБ/с), поэтому код M1–M4 писался параллельно с загрузкой.

## M1: политики, хранилище, классификатор
- `policies.yaml` и `core/policies.py`: валидация (категории, пороги, regex), hot reload по mtime, `allowed_categories(host)` с учётом поддоменов и `never_allowed`.
- `core/store.py`: SQLite в режиме WAL, общая для процесса прокси и процесса API. Таблицы `events` и `dataset`. `examples_for(category)` отдаёт решения security первыми, остальное случайно, отдельно по каждой метке.
- `core/classifier.py`: двухэтапный pipeline detect → policy filter → verify (few-shot по категории) → score. JSON-схема передаётся в `format` Ollama (structured output), `temperature 0`, `think: false`. Общий таймаут 15 с. Любая ошибка поднимает `ClassifierError`, а это BLOCK.
- Вызовы Ollama идут с `trust_env=False`, иначе при включённом системном прокси httpx отправил бы их в собственный прокси.
- Проверено: pipeline на заглушке модели (фильтр по домену, верификация, подсветка offset'ов). Проверка на живой Gemma: см. M5.

## M2: прокси
- `proxy/guard.py`: async-хук `request`. ALLOW пропускает. BLOCK отдаёт 403 с JSON-ошибкой. REVIEW держит запрос: каждые 0,5 с опрашивает SQLite до решения или до таймаута, при таймауте `expired` и 403.
- TLS расшифровывается только для `inspect_domains`: при старте ставится `allow_hosts`, остальное passthrough.
- `proxy/adapters.py`: ChatGPT (`/backend-api/(f/)conversation`, `messages[].content.parts` роли user), Claude (`…/chat_conversations/*/completion`, `prompt` и `attachments[].extracted_content`). Generic-адаптер (JSON-строки, form, text) работает только для inspect-доменов без собственного адаптера, поэтому телеметрия ChatGPT/Claude не уходит в модель.
- `core/notify.py`: уведомление macOS через `terminal-notifier` (клик открывает админку), если он установлен, иначе через `osascript`. Фрагменты в уведомлении маскируются.
- `scripts/dlp-on.sh` / `dlp-off.sh` (`networksetup` на сервисе активного интерфейса) и `run.sh` (Ollama, API, прокси; trap → dlp-off).
- Проверено: `curl -x 127.0.0.1:8080` на `chatgpt.com/backend-api/f/conversation` без модели даёт 403 fail-closed и событие в SSE. `example.com` проходит насквозь (200).
